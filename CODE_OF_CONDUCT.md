# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the work. Harassment and personal
attacks aren't tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour to the maintainers through a
[private security advisory](https://github.com/k6labs-cz/Osiris/security/advisories/new) (it reaches only
them). Maintainers may remove comments, commits and contributors that break these rules.
